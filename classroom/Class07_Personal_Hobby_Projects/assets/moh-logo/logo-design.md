# Miles of Happiness: 로고 디자인 가이드

> 나의 행복찾기 (Finding True Happiness)
> 버전 1.0 · 2026-10-30

---

## 1. 로고 개요

| 항목 | 내용 |
|---|---|
| 로고명 | **MILES OF HAPPINESS** |
| 의미 | 행복을 향해 한 걸음씩 걸어가는 여정 |
| 형태 | 원형 엠블럼 + 3단 워드마크 (MILES / OF / HAPPINESS) |
| 기본 버전 | **Light (Meadow)**: 초록 산책, 쉼과 회복, 자연 속의 행복 |
| 보조 버전 | **Dark**: 어두운 배경, 다크 모드용 |
| 사용처 | Instagram(@ben27182818), Threads 프로필, SNS 및 웹 |

### 컨셉: Meadow (초록 산책)
행복은 멀리 있는 것이 아니라 산책길의 풀잎, 하늘, 바람처럼 일상 속에 있다는 메시지를 담았습니다.
연한 초원색 배경에 짙은 숲색 글자로 차분함과 신뢰감을 주고, 생기 있는 잎사귀 초록을 포인트로 써서 성장과 회복의 느낌을 더했습니다.

## 3. 타이포그래피

| 요소 | 서체 | 굵기 | 크기 (1080px 기준) | 자간 |
|---|---|---|---|---|
| MILES | Google Sans | Bold (700) | 118px | +6px |
| HAPPINESS | Google Sans | Bold (700) | 118px | +3px |
| OF | Google Sans | Medium (500) | 40px | +3px |

- 모든 글자는 **대문자**입니다.
- 최종 파일의 글자는 **벡터 도형(아웃라인)으로 변환**되어 있어서 서체가 설치되지 않은 환경에서도 똑같이 보입니다.
- 서체 라이선스: Google Sans, SIL Open Font License (OFL). 상업적 사용 가능.

## 4. 구성 및 비율 (1080 × 1080 캔버스 기준)

```
            ┌───────────────────────────┐
            │          (원형 배경)        │
            │                           │
            │          M I L E S         │  ← Bold 118px
            │   ───────── OF ─────────   │  ← 가로선 4px + Medium 40px
            │      H A P P I N E S S     │  ← Bold 118px
            │                           │
            └───────────────────────────┘
```

| 항목 | 값 |
|---|---|
| 원 지름 | 1080px (캔버스 전체) |
| 원 테두리 (Light) | 반지름 536px, 두께 8px, Leaf Green 22% 투명도 |
| 글자 묶음 | 원 정중앙(540, 540)에 가로·세로 가운데 정렬 |
| 대문자 높이 | 약 86px |
| MILES 너비 | 약 353px |
| HAPPINESS 너비 | 약 654px (원 지름의 약 61%) |
| 줄 간격 | MILES 아래쪽 ~ HAPPINESS 위쪽 110px, 그 정가운데에 OF 배치 |
| 가로선 | 두께 4px, 끝 둥글게, 양 끝이 HAPPINESS 좌우 끝과 일치 |
| OF ~ 가로선 간격 | 양쪽 각 16px |

## 5. 사용 규칙

### 이렇게 사용하세요
- 밝은 배경, 라이트 모드 화면에는 **Light (Meadow)**를 사용합니다.
- 어두운 배경, 다크 모드 화면에는 **Dark**를 사용합니다.
- 로고 주변에 원 지름의 **10% 이상** 여백을 둡니다.
- 크기를 바꿀 때는 가로세로 비율을 유지합니다. SVG 사용을 권장합니다.

### 피해 주세요
- 글자 배치, 크기 비율, 서체를 바꾸지 않습니다.
- 지정된 색 외의 다른 색을 쓰거나 그라데이션, 그림자를 넣지 않습니다.
- 로고를 늘이거나 찌그러뜨리거나 회전하지 않습니다.
- 복잡한 사진 위에 원 배경 없이 글자만 올리지 않습니다.

### 최소 크기
- 화면: **48px** 이상. 이보다 작으면 "OF"가 잘 보이지 않습니다.
- 인쇄: **15mm** 이상.

| 파일 | 용도 |
|---|---|
| `miles-of-happiness-light.svg` | 라이트 기본 로고 (벡터 원본, 편집·인쇄용) |
| `miles-of-happiness-light-1080.png` | Instagram 등 SNS 프로필 사진 |
| `miles-of-happiness-light-512.png` | 웹, 앱 아이콘 |

| `miles-of-happiness-dark-1080.png` / `-512.png` / `-180.png` | 다크 모드용 PNG |

- PNG는 모두 원 바깥이 **투명 배경**입니다.
- SVG는 VectorCraft, Illustrator, Figma, Inkscape 등에서 바로 편집할 수 있습니다.

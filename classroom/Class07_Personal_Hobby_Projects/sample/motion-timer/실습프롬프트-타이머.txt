내용: [어디에 쓰는 타이머인지 적으세요. 정해 둔 시간이 있으면 함께 적으세요. 예: 점심시간 60분 / 발표 시간 5분 / 시험 시간 50분]

첨부한 motion-template-timer.html을 그대로 복사해서 시작하세요. 이 파일은 참고 이미지가 아니라 작동하는 원본입니다. 흰 바탕에 검은 큰 숫자로 남은 시간을 거꾸로 세는 한 장짜리 HTML 타이머입니다. 시간을 적고 Enter를 누르면 큰 분 숫자와 오른쪽 위 작은 초 숫자가 줄어들고, 바뀌는 숫자 자리만 조각과 색 번짐으로 넘어갑니다. 1분 남으면 한 음, 끝나면 세 음이 울리고, 검은 판이 아래에서 차오르며 끝 문구가 뜹니다. 위 내용란에 맞게 글만 바꿔 실제 presentation.html 파일로 완성하세요. 시청자는 내용란만 바꿉니다. 첨부 파일에 든 글은 예시(강의 쉬는 시간)입니다. 모두 내용란에 적힌 쓰임새로 바꾸세요. 내용란이 대괄호 그대로이면 대괄호 안 예시 가운데 첫 번째로 만드세요.

[편집 범위: 반드시 지키세요]
1. 원본의 편집 계약 주석(PRESENTATION_EDIT_CONTRACT)과 presentation-data JSON을 먼저 읽으세요. 파일을 읽지 못하면 중단 사유를 말하세요.
2. 수정할 곳은 <script type="application/json" id="presentation-data"> 안의 JSON 한 곳뿐입니다. 속성 순서가 달라도 이 id의 JSON 본문을 찾으세요. CSS, 실행 JavaScript, HTML 구조, 글꼴, 라이선스, 클래스, ID, data-* 속성은 한 글자도 바꾸지 마세요. 도구의 레이아웃 검사를 맞추려고 구조나 속성을 덧붙이지 마세요. 일반 HTML 파일이며 PPTX용 슬라이드로 변환하거나 새 포장 파일로 감싸지 마세요.
3. JSON 파서로 읽고 객체를 수정한 뒤 JSON 직렬화기로 저장하세요. 정규식으로 개별 문장이나 코드 괄호를 바꾸지 마세요. 원본 JSON의 키 이름, 필수 필드, 자료형을 그대로 지키고 새 키를 더하지 마세요. 실행 코드나 함수 문자열을 JSON에 넣지 마세요. 문자열의 <는 \u003c로 이스케이프하세요.
4. 내장 글꼴의 거대한 base64는 복사로 보존하고 모델에 읽어 들이거나 다시 출력하지 마세요. 외부 리소스는 추가하지 마세요. 최종 결과는 인터넷 연결 없이 작동하는 단일 HTML입니다.

[주제에 맞게 바꿀 내용]
이 타이머에서 바꿀 글은 아래 일곱 칸뿐입니다. 시간 해석, 움직임, 소리, 단축키 안내(F 전체화면, Space 멈춤, ↑↓ 1분, Enter 처음으로)는 JSON 밖의 고정 부분이라 그대로 둡니다.
- title: 화면 위 왼쪽 이름이자 브라우저 탭 이름입니다(10자 이하). 무엇을 기다리는 시간인지 짧게 쓰세요. 예: 점심시간, 발표 시간
- inputLabel: 시간을 넣는 칸 앞에 붙는 말입니다(8자 이하). 예: 쉴 시간, 발표 시간, 남은 시간
- defaultMinutes: 칸을 비운 채 Enter를 누르면 세는 분입니다(1~600 사이 숫자). 내용란에 시간이 있으면 그 분을 쓰세요. 없으면 그 쓰임새에 흔한 시간을 고르세요.
- backLine: 도는 동안 「오후 2시」 같은 끝 시각 바로 뒤에 붙는 말입니다(14자 이하). 「에」로 시작하세요. 끝 시각과 이어 읽어 한 문장이 되는지 보세요. 예: 「에 다시 시작합니다」 → 오후 2시에 다시 시작합니다 / 「에 발표가 끝납니다」
- doneLine: 시간이 다 되면 검은 화면에 뜨는 말입니다(14자 이하). 예: 다시 시작합니다, 발표를 마칩니다
- pauseLine: 멈췄을 때 뜨는 말입니다(8자 이하). 예: 잠시 멈춤
- topic: 이 타이머의 쓰임새를 40자 이하로 적으세요.
- 말투: 화면 글은 원본 「다시 시작합니다」처럼 짧고 쉬운 「~합니다」 꼴로 쓰세요. 소리 내어 읽었을 때 어색하면 고쳐 쓰세요.
- 원본 예시 낱말(쉬는 시간, 쉴 시간, 다시 시작합니다)은 내용란의 쓰임새와 맞지 않으면 남기지 마세요. 글자 수 제한(maxChars)을 지키세요.

[완료 전 확인]
- JSON을 다시 읽어 파싱 성공과 계약의 schema, maxChars를 확인하세요. 키가 원본과 같은지, defaultMinutes가 1~600 사이 숫자인지, backLine이 「에」로 시작하는지 확인하세요.
- JSON 본문만 같은 표식으로 가린 원본과 결과의 나머지 바이트가 정확히 같은지 대조하세요. 다르면 JSON 밖 변경을 원본으로 되돌리세요.
- 실제 브라우저가 있으면 직접 열어 「자료 설정을 확인해 주세요」 화면이 뜨지 않는지 보세요. 칸에 1을 적고 Enter를 눌러 숫자가 줄어드는지, Space로 멈추고 이어지는지, ↑↓로 1분씩 바뀌는지, 끝나면 검은 화면에 doneLine이 뜨는지, Enter로 처음 화면에 돌아오는지 확인하세요. 1366×768, 1920×1080에서 잘림과 겹침을 확인하세요. 검사하지 못한 항목은 검증됐다고 쓰지 마세요.

[내용란] 아래 대괄호를 지우고 원하는 내용을 적으세요. 나머지는 그대로 두세요.
내용: [1년 동안 시간을 쓰는 일 한 가지를 적으세요. 예: 회의 / 출퇴근 / 쇼츠 보기 / 보고서 쓰기]

첨부한 motion-template-365.html을 그대로 복사해서 시작하세요. 이 파일은 참고 이미지가 아니라 작동하는 원본입니다. 「1년 365일 중 이 일에 며칠을 쓰는가」를 보여 주는 한 장짜리 HTML 발표 자료이고, 숫자를 누르면 365칸이 바뀌고 화면을 넘기면 같은 칸이 막대와 고리로 모양을 바꿉니다. 위 내용란에 맞게 자료만 바꿔 실제 presentation.html 파일로 완성하세요. 시청자는 내용란만 바꿉니다. 첨부 파일에 든 주제와 숫자는 예시입니다. 모두 내용란에 적힌 일로 바꾸세요. 내용란이 대괄호 그대로이면 대괄호 안 예시 가운데 첫 번째로 만드세요.

[편집 범위: 반드시 지키세요]
1. 원본의 편집 계약 주석(PRESENTATION_EDIT_CONTRACT)과 presentation-data JSON을 먼저 읽으세요. 파일을 읽지 못하면 중단 사유를 말하세요.
2. 수정할 곳은 <script type="application/json" id="presentation-data"> 안의 JSON 한 곳뿐입니다. 속성 순서가 달라도 이 id의 JSON 본문을 찾으세요. CSS, 실행 JavaScript, HTML 구조, 글꼴, 라이선스, 클래스, ID, data-* 속성은 한 글자도 바꾸지 마세요. 도구의 레이아웃 검사를 맞추려고 구조나 속성을 덧붙이지 마세요. 일반 HTML 파일이며 PPTX용 슬라이드로 변환하거나 새 포장 파일로 감싸지 마세요.
3. JSON 파서로 읽고 객체를 수정한 뒤 JSON 직렬화기로 저장하세요. 정규식으로 개별 문장이나 코드 괄호를 바꾸지 마세요. 원본 JSON의 키 이름, 필수 필드, 배열 길이, 자료형을 그대로 지키세요. 실행 코드나 함수 문자열을 JSON에 넣지 마세요. 문자열의 <는 \u003c로 이스케이프하세요.
4. 내장 글꼴의 거대한 base64는 복사로 보존하고 모델에 읽어 들이거나 다시 출력하지 마세요. 외부 리소스는 추가하지 마세요. 최종 결과는 인터넷 연결 없이 작동하는 단일 HTML입니다.

[주제에 맞게 바꿀 내용]
이 자료의 계산은 하나입니다. 숫자 셋 × 고정값을 곱해 1년에 쓰는 시간을 내고, 하루 시간으로 나눠 날로 바꿉니다.
- 숫자 셋(variables)과 고정값(fixed): 곱하면 「1년 동안 이 일에 쓰는 양」이 되도록 주제를 쪼개세요. 예: 한 주에 하는 회의 5번 × 52주 × 한 번에 다루는 안건 3개 × 안건 하나 20분. 숫자가 둘밖에 안 나오면 일을 한 단계 더 쪼개세요. 뜻 없는 배수나 점수를 만들지 마세요.
- 고정값은 12달(12), 52주(52), 365일(365) 중 첫 숫자의 기준에 맞는 것으로 정하세요(한 달에 몇 번이면 12, 한 주에 몇 번이면 52, 하루에 몇 번이면 365). fixed의 label은 원본처럼 「1년」으로 두세요.
- toHours: 곱한 값을 시간으로 바꾸는 나눗수입니다. 마지막 단위가 초면 3600, 분이면 60, 시간이면 1.
- dayHours: 일하는 시간에 쓰는 일이면 8, 깨어 있는 시간에 쓰는 일이면 16으로 하고, 무엇을 기준으로 나눴는지 footnote에 적으세요.
- 범위: 숫자마다 min, max, step, 기본값(value)을 평범한 사람이 고를 만한 값으로 정하세요. 세 숫자를 모두 max로 올려도 365일 이하, 기본값으로 1일 이상이어야 합니다. 직접 계산해서 확인하세요.
- 문장: 제목과 세 장면의 머리글, 설명, 표의 이름, 범례를 모두 새 주제로 바꾸세요. 원본 주제(PPT)의 낱말을 남기지 마세요. {days} {hours} {back} {goal} {v1} {v2} {v3} 자리는 계약 주석의 뜻대로 쓰고, 계약이 필수라고 적은 자리는 빼지 마세요. 자리 뒤 조사는 받침에 맞추세요(60일을, 480시간이, 30분이, 30초가, 30%를). 글자 수 제한(maxChars)을 지키고 한 문장에 한 뜻만 담으세요.
- 말투: 화면에 나오는 글은 옆 사람에게 말하듯 쉬운 「~요」 말투로 쓰세요. 책에서나 쓰는 말(한 해, ~하는 것이다)과 숫자나 물건을 사람처럼 쓰는 표현(고집이 세다, 떠난다)은 쓰지 마세요. 소리 내어 읽었을 때 어색하면 고쳐 쓰세요.
- frame의 네 칸은 영문과 숫자, 기호만 쓸 수 있습니다.
- 이 자료의 숫자는 보는 사람이 직접 바꾸는 예시 계산입니다. 통계나 조사 결과처럼 쓰지 말고, 논문, 조사, 링크, 효과를 지어내지 마세요. footnote는 「예시 계산이에요.」로 시작하세요.

[완료 전 확인]
- JSON을 다시 읽어 파싱 성공과 계약의 schema, maxChars, limit를 확인하세요. 기본값, 모두 최솟값, 모두 최댓값 세 경우의 시간과 날을 계산해 적으세요.

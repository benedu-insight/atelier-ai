1. 개요

납기가 여러 차례 연기된 발주 건에 대해 Veltra Systems로부터 PO 취소 요청을 받았습니다. 각 PO의 진행 상태를 확인해 취소 가능 여부를 나누고, 이미 확보한 모델 전용 부품에 대한 취소 비용 보상을 아래와 같이 제안합니다.

3. 취소 불가 항목 (완제품)

PO 7100-2655의 두 모델 4대는 이미 완제품으로 생산이 끝나 취소할 수 없습니다. 전량 인수를 요청드립니다.

4. 취소 비용 보상 제안

부품만 확보한 보류 PO의 경우, 해당 모델 전용으로 구매한 부품은 다른 모델에 쓸 수 없습니다. 모델별 전용 부품 금액을 보상 기준으로 제안합니다. 세부 부품 목록은 별첨 엑셀.

운전자가 아는 것

우리 — 몇 시간을 배워 원하는 곳에 간다

목적지무엇을 만들지 정한다. 누가, 언제, 어떤 화면에서 쓰는가.
길 안내AI에게 정확히 말한다. 목표 · 재료 · 제약 · 확인 방법.
계기판 읽기결과를 눈으로 확인하고 검산한다. 숫자가 맞는가, 빠진 칸은 없는가.
교통 법규고객 정보, 단가, 도면 같은 기밀은 넣지 않는다. 저작권을 지킨다.

운전면허는 정비사 자격증보다 훨씬 빨리 딴다. 그 운전법이 바이브코딩이다.

바이브코딩 VIBE CODING

코드를 직접 쓰지 않고, 원하는 것을 말로 설명해 AI가 코드를 쓰게 하는 방식. 2025년 초 AI 연구자 안드레이 카파시(Andrej Karpathy)가 처음 쓴 말이다.

현장에서는 이미 하는 일

도면 → 시제품 → 검사 → 설계 변경. 시제품 개발과 같은 순환이다. 다른 점은 한 바퀴가 몇 주가 아니라 몇 분이라는 것.

달라지는 것

전통 개발
언어 공부 → 설계 → 코드 작성 → 오류 수정
